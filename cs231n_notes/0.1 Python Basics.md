# Python Basics (from CS231n)

# 1. 基础数据类型

## 1.1 Numbers：数字

Python 中常见的数字类型：

```python
x = 3       # int，整数
y = 3.5     # float，浮点数
```

常见运算：

```python
3 + 2   # 加法
3 - 2   # 减法
3 * 2   # 乘法
3 / 2   # 普通除法，结果 1.5
3 // 2  # 整除，结果 1
3 % 2   # 取余，结果 1
2 ** 3  # 幂运算，结果 8
```

自增写法：

```python
x += 1
```

等价于：

```python
x = x + 1
```

Python 没有：

```python
x++
```

---

## 1.2 Boolean：布尔值

布尔值只有：

```python
True
False
```

本质：

```text
一个判断
↓
成立吗？
↓
True / False
```

例如：

```python
3 > 2
# True

3 == 5
# False
```

注意：

```python
x = 3
```

是赋值。

而：

```python
x == 3
```

是判断是否相等。

常见逻辑运算：

```python
and
or
not
```

例如：

```python
x > 0 and x < 10
```

表示两个条件都必须成立。

---

# 2. String：字符串

字符串用于表示文本：

```python
s = "hello"
```

类型：

```python
str
```

单引号和双引号都可以：

```python
"hello"
'hello'
```

## 2.1 字符串拼接

```python
hello = "hello"
world = "world"

hello + " " + world
```

结果：（这里的 “ ” 是在 hello 和 world 之间添加空格）

```text
hello world
```

这里的 `+` 会根据数据类型执行不同操作：

```text
数字 + 数字
→ 数学加法

字符串 + 字符串
→ 字符串拼接
```

例如：

```python
3 + 4
# 7
```

而：

```python
"3" + "4"
# "34"
```

---

## 2.2 字符串长度和方法

字符串长度：

```python
len("hello")
# 5
```

常见方法：

```python
s = "hello"

s.upper()
# "HELLO"

s.capitalize()
# "Hello"
```

这里：

```text
s.upper
→ 方法本身

s.upper()
→ 调用方法
```

---

## 2.3 字符串是 immutable

字符串属于：

> immutable object，不可变对象

例如：

```python
s = "hello"
```

不能：

```python
s[0] = "H"
```

如果想得到：

```text
Hello
```

需要创建新的字符串：

```python
s = "H" + s[1:]
```

流程：

```text
原字符串 "hello"
↓
取出 s[1:]
↓
"ello"

"H" + "ello"
↓
创建新字符串 "Hello"
```

---

## 2.4 字符串格式化

字符串格式化用于：

> 把变量或表达式方便地嵌入字符串中。

例如：

```python
name = "Alice"
age = 20
```

如果不用格式化：

```python
sentence = name + " is " + str(age) + " years old"
```

需要手动把整数：

```python
age
```

转换成字符串：

```python
str(age)
```

更推荐使用 f-string：

```python
sentence = f"{name} is {age} years old"
```

执行逻辑：

```text
{name}
↓
"Alice"

{age}
↓
20

↓

"Alice is 20 years old"
```

机器学习中常见：

```python
epoch = 5
loss = 0.234

print(f"Epoch {epoch}, loss = {loss}")
```

输出：

```text
Epoch 5, loss = 0.234
```

`{}` 内还可以直接放表达式：

```python
x = 3

print(f"x squared is {x ** 2}")
```

输出：

```text
x squared is 9
```

旧式格式化：

```python
"%s %d" % (name, age)
```

其中：

```text
%s
→ 字符串占位符

%d
→ 整数占位符
```

旧式 `%` 格式化只需要看得懂。

自己写代码时优先：

```python
f"..."
```

# 3. List：列表

list 是：

> 有顺序、可以修改、允许重复元素的数据结构。

例如：

```python
nums = [10, 20, 30, 40]
```

## 3.1 索引 index

```text
值：       10   20   30   40
正索引：    0    1    2    3
负索引：   -4   -3   -2   -1
```

例如：

```python
nums[0]
# 10

nums[-1]
# 40
```

负索引从 `-1` 开始，因为：

```text
-0 = 0
```

---

## 3.2 list 是 mutable

```python
nums = [10, 20, 30]
nums[1] = 999
```

得到：

```python
[10, 999, 30]
```

---

## 3.3 append / remove / pop / del

追加元素：

```python
nums.append(40)
```

作用：

```text
添加到 list 最后
```

按 value 删除：

```python
nums.remove(20)
```

按 index 删除并返回元素：

```python
x = nums.pop(1)
```

按 index 删除但不返回：

```python
del nums[1]
```

|操作|根据什么删除|返回被删元素|
|---|---|---|
|`remove(value)`|value|否|
|`pop(index)`|index|是|
|`del x[index]`|index|否|

`pop()` 如果不写 index：

```python
nums.pop()
```

默认删除并返回最后一个元素。

---

## 3.4 slicing：切片

完整形式：

```python
list[start:end:step]
```

规则：

```text
包含 start
不包含 end
```

即：

```text
[start, end)
```

例如：

```python
nums = [0, 1, 2, 3, 4]

nums[1:4]
```

结果：

```python
[1, 2, 3]
```

常见形式：

```python
nums[:3]     # 从开头到 index 3 之前
nums[2:]     # 从 index 2 到最后
nums[:]      # 全部
nums[::2]    # 每隔 2 个取一次
nums[::-1]   # 反转
```

---

## 3.5 遍历

```python
animals = ["cat", "dog", "fish"]

for animal in animals:
    print(animal)
```

---

## 3.6 enumerate()

`enumerate` 中文通常叫：

> 枚举函数

作用：

> 给元素附带 index。

```python
for i, animal in enumerate(animals):
    print(i, animal)
```

可以理解为产生：

```text
(0, "cat")
(1, "dog")
(2, "fish")
```

再通过 tuple unpacking：

```text
i, animal = (0, "cat")
```

---

## 3.7 List comprehension：列表推导式

`comprehension` 在 Python 中可记为：

> 推导式

核心：

```text
一边遍历
↓
一边构造新的容器
```

例如：

```python
nums = [0, 1, 2, 3, 4]

squares = [x ** 2 for x in nums]
```

等价于：

```python
squares = []

for x in nums:
    squares.append(x ** 2)
```

最终：

```python
[0, 1, 4, 9, 16]
```

也可以加条件：

```python
even_nums = [x for x in nums if x % 2 == 0]
```

# 4. Dict：字典

核心结构：

```text
key → value
键 → 值
```

例如：

```python
person = {
    "name": "Alice",
    "age": 20
}
```

## 4.1 访问

```python
person["age"]
# 20
```

list 和 dict 的区别：

```text
list
→ index → value

dict
→ key → value
```

---

## 4.2 添加和修改

```python
person["major"] = "Bioinformatics"
```

如果 key 不存在：

```text
→ 添加
```

如果 key 已存在：

```text
→ 修改 value
```

---

## 4.3 `in`

```python
"name" in person
```

判断：

> key 是否存在。

对 dict 使用 `in` 时默认检查 key。

---

## 4.4 `get()`

```python
person.get("age")
```

存在：

```text
→ 返回 value
```

不存在：

```text
→ 返回 None
```

也可以指定默认值：

```python
person.get("height", "unknown")
```

---

## 4.5 遍历

所有 key：

```python
person.keys()
```

所有 value：

```python
person.values()
```

所有 key-value：

```python
person.items()
```

例如：

```python
for key, value in person.items():
    print(key, value)
```

`items()` 可以理解为产生：

```text
(key, value)
```

形式的数据。

---

## 4.6 Dictionary comprehension

```python
nums = [1, 2, 3]

squares = {x: x ** 2 for x in nums}
```

得到：

```python
{
    1: 1,
    2: 4,
    3: 9
}
```

# 5. Set：集合

特点：

```text
不允许重复
不依赖固定顺序
不能按 index 访问
```

例如：

```python
animals = {"cat", "dog", "fish"}
```

## 5.1 去重

```python
animals = ["cat", "dog", "cat", "fish"]

unique_animals = set(animals)
```

得到：

```text
{"cat", "dog", "fish"}
```

---

## 5.2 add()

```python
animals.add("bird")
```

区别：

```text

→ 添加到 list 最后

set.add(x)
→ 添加到 set
→ 没有“最后”的概念
```

---

## 5.3 remove() 和 discard()

```python

```

如果不存在会报错。

```python
animals.discard("cat")
```

如果不存在不会报错。

`discard` 可理解为：

> 丢弃 / 舍弃

## 5.4 集合运算


对称差集：

```python
a ^ b
```

## 5.5 Set comprehension

# 6. Tuple：元组

特点：

```text
有顺序
可以使用 index
不可修改
```

例如：

```python
point = (3, 5)
```

## 6.1 Packing

```python
point = 3, 5
```

等价于：

```python
point = (3, 5)
```

过程：

```text
3
5
↓
packing
↓
(3, 5)
```

---

## 6.2 Unpacking

```python
point = (3, 5)

x, y = point
```

得到：

```text
x = 3
y = 5
```

---

## 6.3 tuple 的关键是逗号

```python
x = 3, 5
```

就是：

```python
(3, 5)
```

而：

```python
x = (3)
```

只是整数 `3`。

单元素 tuple：

```python
x = (3,)
```

因此：

```python
shape = (3,)
```

表示一个只有一个元素的 tuple。

---

## 6.4 Packing / unpacking 常见场景

### enumerate()

```python
for i, animal in enumerate(animals):
```

每次得到：

```text
(index, value)
```

然后 unpack。

### dict.items()

```python
for key, value in person.items():
```

每次得到：

```text
(key, value)
```

然后 unpack。

### 函数返回多个值

```python
def get_point():
    return 3, 5
```

等价于：

```python
def get_point():
    return (3, 5)
```

调用：

```python
x, y = get_point()
```

流程：

```text
return (3, 5)
↓
x, y = (3, 5)
↓
x = 3
y = 5
```

# 7. 容器和可变性总结

## 7.1 空容器写法

|类型|空容器写法|
|---|---|
|`list`|`[]`|
|`dict`|`{}`|
|`tuple`|`()`|
|`set`|`set()`|

注意：

```python
()
```

表示空 tuple，不是空 set。

---

## 7.2 Mutable / immutable / hashable

|类型|中文|Mutable|Hashable|可作为普通 dict key|有 index|
|---|---|--:|--:|--:|--:|
|`str`|字符串|❌|✅|✅|✅|
|`list`|列表|✅|❌|❌|✅|
|`tuple`|元组|❌|通常 ✅|通常 ✅|✅|
|`dict`|字典|✅|❌|❌|不按整数 index|
|`set`|集合|✅|❌|❌|❌|

tuple 是否 hashable 取决于内部元素。

例如：

```python
(1, 2)
```

通常可 hash。

但：

```python
([1, 2], 3)
```

包含 list，因此不可 hash。

# 8. Functions：函数

函数用于：

> 把一段可重复执行的操作封装起来。

```python
def add(a, b):
    return a + b
```

## 8.1 Parameter 和 argument

定义函数：

```python
def add(a, b):
```

这里：

```text
a, b
→ parameters
→ 形参
```

调用：

```python
add(3, 5)
```

这里：

```text
3, 5
→ arguments
→ 实参
```

---

## 8.2 Positional arguments

```python
subtract(10, 3)
```

按位置对应参数。

---

## 8.3 Keyword arguments

```python
subtract(a=10, b=3)
```

明确指定参数。

机器学习中常见：

```python
DataLoader(
    dataset,
    batch_size=32,
    shuffle=True
)
```

---

## 8.4 Default arguments

```python
def greet(name, message="Hello"):
    print(message, name)
```

如果不传：

```python
greet("Alice")
```

使用默认值：

```text
message = "Hello"
```

也可以覆盖：

```python
greet("Alice", "Hi")
```

---

## 8.5 return

`return`：

```text
返回结果
+
立即结束函数
```

例如：

```python
def square(x):
    return x ** 2
```

```python
result = square(4)
```

流程：

```text
square(4)
↓
return 16
↓
result = 16
```

---

## 8.6 return 和 print

```text
return
→ 把结果交出去

print
→ 把内容显示出来
```

如果函数没有显式 `return`：

```python
def greet():
    print("hello")
```

默认返回：

```python
None
```

# 9. Classes：类

class 用于：

> 定义一种对象拥有什么数据，以及能执行什么操作。

完整例子：

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def greet(self, person):
        print(f"{self.name} says hello to {person}")


dog1 = Dog("Milo")

dog1.greet("Alice")
```

## 9.1 Class 和 instance

```python
Dog
```

是：

> class，类 / 模板

```python
dog1 = Dog("Milo")
```

这里的 `dog1` 是：

> instance，实例 / 对象

---

## 9.2 `__init__`

```python
def __init__(self, name):
```

是初始化方法。

创建对象：

```python
dog1 = Dog("Milo")
```

时自动执行。

---

## 9.3 self

`self` 表示：

> 当前实例本身。

创建：

```python
dog1 = Dog("Milo")
```

时：

```text
self = dog1
name = "Milo"
```

因此：

```python
self.name = name
```

相当于：

```text
dog1.name = "Milo"
```

---

## 9.4 Attribute

```python
dog1.name
```

是：

> attribute，属性

即对象保存的数据。

---

## 9.5 Method

```python
dog1.greet
```

表示：

> 访问方法本身

而：

```python
dog1.greet("Alice")
```

表示：

> 调用方法

括号 `()` 才会真正执行。

---

## 9.6 完整执行流

```python
dog1 = Dog("Milo")
```

流程：

```text
创建 Dog 实例
↓
调用 __init__
↓
self = dog1
name = "Milo"
↓
self.name = "Milo"
↓
dog1.name = "Milo"
```

然后：

```python
dog1.greet("Alice")
```

流程：

```text
self = dog1
person = "Alice"

↓

self.name
→ dog1.name
→ "Milo"

↓

输出：
Milo says hello to Alice
```
