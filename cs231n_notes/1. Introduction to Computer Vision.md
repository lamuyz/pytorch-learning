# CS231n Lecture 1：Introduction to Computer Vision

## 1. Computer Vision 是什么

**Computer Vision，CV：计算机视觉**

目标是让计算机从图像或视频中获取和理解视觉信息。

对计算机来说，图像最开始只是数字：

```text
image
↓
pixels
↓
tensor
```

例如 RGB 图像：

**RGB = Red, Green, Blue，红、绿、蓝。**

PyTorch 中：

```python
x.shape
```

可能得到：

```text
[1, 3, 128, 128]
```

表示：

```text
batch
channels
height
width
```

计算机视觉的核心可以理解为：

```text
raw pixels
↓
visual representation
↓
semantic understanding / prediction
```

---

## 2. Visual Representation

**Visual Representation：视觉表征**

视觉信息通常是逐层变得越来越抽象的：

```text
pixels
↓
edges / local patterns
↓
textures / shapes
↓
higher-level structures
↓
semantic information
```

这和 U-Net Encoder 很接近：

```text
image
↓
DoubleConv
↓
Down
↓
DoubleConv
↓
...
↓
Bottleneck
```

因此 Encoder 不只是“把图片变小”，还在逐层学习越来越抽象的视觉特征。

---

## 3. CNN 的历史思想来源

早期视觉研究发现，视觉系统中的神经元会对特定方向的边缘和局部视觉模式产生响应。

例如：

```text
|
/
—
```

这种局部模式检测思想后来影响了 convolution（卷积）等计算机视觉方法。

例如：

```python
nn.Conv2d(...)
```

可以学习对不同局部模式产生响应的 convolution kernel。

现代 CNN 并不是直接复制人脑，而是受到部分视觉系统思想启发。

---

## 4. 从传统视觉到 Deep Learning

传统 Computer Vision 往往依赖人工设计规则和特征：

```text
image
↓
hand-crafted features
↓
classifier
```

例如：

```text
edge
corner
texture
shape
```

其中：

**Hand-crafted Features：手工设计特征**

Deep Learning 的重要变化是：

```text
image
↓
neural network
↓
learned features
↓
prediction
```

即：

> 具体哪些视觉特征重要，不再主要由人手工规定，而是由模型从数据中学习。

---

## 5. Neural Networks + GPUs + Big Data

现代 Deep Learning 的快速发展来自多个条件逐渐成熟：

```text
Neural Networks
+
GPUs
+
Big Data
↓
Modern Deep Learning
```

CNN 并不是 2012 年才出现。

更准确的历史路线可以概括为：

```text
Neocognitron
↓
LeNet
↓
ImageNet + GPU
↓
AlexNet

现代深度视觉模型
```

2012 年 AlexNet 是重要转折点之一。

## 6. Computer Vision 的主要任务

### Image Classification

**Image Classification：图像分类**

```text
image
↓
一个类别
```

例如：

```text
cat / dog
```

---

### Object Detection

**Object Detection：目标检测**

```text
image
↓
类别 + bounding box
```

回答：

```text
是什么？
在哪里？
```

---

### Semantic Segmentation

**Semantic Segmentation：语义分割**

```text
image
↓
每个 pixel 一个类别
```

例如：

```text
0 = background
1 = cell
```

U-Net 主要属于这一类任务。

---

### Instance Segmentation

**Instance Segmentation：实例分割**

不仅判断 pixel 属于什么类别，还要区分不同实例：

```text
cell 1
cell 2
cell 3
```

---

## 7. U-Net 与 Lecture 1 的联系

U-Net 可以从视觉表征角度理解为：

```text
raw pixels
↓
Encoder
↓
hierarchical visual features
↓
Bottleneck
↓
Decoder
↓
recover spatial information
↓
pixel-level prediction
```

所以：

```text
Encoder
```

负责逐渐提取更抽象的视觉信息，

而：

```text
Decoder
```

负责把这些信息重新映射回空间位置。

---

## 8. Lecture 1 核心总结

Lecture 1 最重要的是建立这几个认识：

```text
1. 图像对计算机来说最开始只是数字

2. Computer Vision 的核心是：
   pixels → representation → understanding

3. 传统 CV 主要依赖 hand-crafted features

4. Deep Learning 可以自动学习 useful features

5. Image Classification、Detection、Segmentation
   是不同层次的视觉任务

6. U-Net 属于 pixel-level prediction 模型
```
