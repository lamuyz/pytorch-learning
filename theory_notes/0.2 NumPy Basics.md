# 1. NumPy 与 ndarray

NumPy（Numerical Python）主要用于高效的数值计算、数组与矩阵运算。

核心数据结构：

> **ndarray = n-dimensional array = n 维数组**

```python
import numpy as np

x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

NumPy ndarray 通常使用统一的 `dtype`。

## 核心属性

对于：

```python
x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

有：

```text
x.shape
→ (2, 3)
→ 每个维度的长度

x.ndim
→ 2
→ dimension 的数量，即二维数组

x.size
→ 6
→ 总元素数量

x.dtype
→ 元素的数据类型
```

三者关系例如：

```text
shape = (2, 3, 4)

ndim = 3

size = 2 × 3 × 4
     = 24
```

### 一维与二维需要区分

```python
np.array([1, 2, 3])
```

```text
shape = (3,)
→ 一维
```

```python
np.array([[1, 2, 3]])
```

```text
shape = (1, 3)
→ 二维，1 行 3 列
```

```python
np.array([
    [1],
    [2],
    [3]
])
```

```text
shape = (3, 1)
→ 二维，3 行 1 列
```

# 4. Integer Array Indexing：整数数组索引

Integer array indexing：

> 使用一组整数索引，一次指定多个位置。

例如：

```python
a = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
])

rows = np.array([0, 1, 2])
cols = np.array([2, 1, 0])

result = a[rows, cols]
```

NumPy 一一配对：

```text
(0,2)
→ a[0,2]
→ 30

(1,1)
→ a[1,1]
→ 50

(2,0)
→ a[2,0]
→ 70
```

所以：

```text
result = [30 50 70]
```

也可以直接：

```python
a[[0, 1, 2], [2, 1, 0]]
```

## 和 slicing 的区别

```python
a[1:4]
```

是：

```text
slicing
→ 取一个连续范围
```

而：

```python
a[[0, 2, 4]]
```

是：

```text
integer array indexing
→ 指定多个离散位置
```

NumPy ndarray 相比普通 Python list，还额外支持 integer array indexing 和 boolean array indexing。

# 5. Boolean Array Indexing：布尔数组索引

使用 `True / False` 决定元素是否保留。

```python
a = np.array([10, 20, 30, 40, 50])

mask = a > 25
```

得到：

```text
[False False True True True]
```

然后：

```python
a[mask]
```

得到：

```text
[30 40 50]
```

也可以：

```python
a[a > 25]
```

NumPy 数组逐元素逻辑常用：

```text
&
→ AND

|
→ OR

~
→ NOT
```

例如：

```python
a[(a > 20) & (a < 50)]
```

得到：

```text
[30 40]
```

# 7. Axis：轴

`axis` 可以理解为数组不同维度对应的方向。

对于：

```text
shape = (2, 3)
```

有：

```text
axis 0
→ 第 0 个维度
→ 长度 2

axis 1
→ 第 1 个维度
→ 长度 3
```

因此：

```text
shape = (2, 3, 4)
         ↑  ↑  ↑
       axis0 1  2
```

数组的维度越高，拥有的 axes 越多：

```text
1D → 1 个 axis
2D → 2 个 axes
3D → 3 个 axes
...
```

`axes` 是 `axis` 的复数。

可以把 axes 类比为坐标系中的不同方向，但不能机械对应为 x / y / z 轴。

## 用 shape 判断 axis

```python
x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

```text
x.shape = (2, 3)
```

执行：

```python
x.sum(axis=0)
```

表示消掉：

```text
axis 0
↓
(2, 3)
 ↑
```

因此结果 shape：

```text
(3,)
```

实际：

```text
[1+4, 2+5, 3+6]
↓
[5, 7, 9]
```

执行：

```python
x.sum(axis=1)
```

表示消掉：

```text
axis 1
↓
(2, 3)
    ↑
```

因此结果：

```text
(2,)
```

实际：

```text
[1+2+3, 4+5+6]
↓
[6, 15]
```

所以相比死记：

```text
axis=0 → 按列
axis=1 → 按行
```

更推荐记：

> **axis 指定的是要沿哪个维度运算 / 聚合掉哪个维度。**

# 8. 矩阵乘法

NumPy 中：

```python
A @ B
```

表示普通矩阵乘法。

矩阵乘法规则：

> 左矩阵的一行和右矩阵的一列做点积。

例如：

```text
X.shape = (500, 3072)

W.shape = (3072, 10)
```

`X` 的每一行有 3072 个数，`W` 的每一列也有 3072 个数，因此可以做：

```text
x1×w1
+
x2×w2
+
...
+
x3072×w3072
```

`X` 有 500 行，`W` 有 10 列，因此：

```text
每个样本
→ 得到 10 个结果

500 个样本
→ 得到 500 × 10 个结果
```

所以：

```text
(500, 3072) @ (3072, 10)

→ (500, 10)
```

二维情况下：

```python
A @ B
A.dot(B)
np.dot(A, B)
```

都可以完成普通矩阵乘法。

# 9. 权重矩阵与全连接层

全连接层核心数学可以理解为：

```text
x @ W + b
```

例如：

```text
3 个输入
→ 2 个输出
```

那么：

```text
W.shape = (3, 2)
```

每个 weight（权重）表示：

> 某个输入对某个输出影响有多大。

所有输入与输出之间的权重组织起来，就是：

> **weight matrix，权重矩阵**

# 10. Broadcasting：广播机制

Broadcasting：

> 不同 shape 的数组在满足规则时，可以直接进行逐元素运算。

判断规则：

```text
1. 写出两个 shape

2. 从右边对齐

3. 左侧缺失的维度看作 1

4. 每一维必须：
   - 相等
   或
   - 其中一个为 1
```

例如：

```text
A.shape = (2, 3)
B.shape =    (3,)
```

右对齐：

```text
A: (2, 3)
B: (1, 3)
```

比较：

```text
2 vs 1
→ OK

3 vs 3
→ OK
```

因此可以广播。

一维数组之所以经常能广播，并不是额外规则，而是因为右对齐后左侧缺失的维度可以视作 `1`。

## shape 决定哪些 axis 被扩展

例如：

```text
X.shape = (2, 3)
y.shape = (3,)
```

右对齐：

```text
X: (2, 3)
y: (1, 3)
```

第 0 维：

```text
1 → 2
```

所以可以概念上理解成：

```text
[10 20 30]
↓
[10 20 30]
[10 20 30]
```

# 11. Reshape 与 Flatten

## Reshape

`reshape()`：

> 在总元素数不变的情况下重新组织 shape。

例如：

```python
x = np.array([1, 2, 3, 4, 5, 6])

x.reshape(2, 3)
```

得到：

```text
[[1 2 3]
 [4 5 6]]
```

`-1` 表示：

> 该维度由 NumPy 根据总元素数量自动推算。

例如：

```python
x.reshape(2, -1)
```

总共 6 个元素：

```text
2 × ? = 6
↓
? = 3
```

所以：

```text
shape = (2, 3)
```

---

## Flatten

Flatten：

> 把多个维度合并，最常见是拉成一维。

例如：

```python
x = np.array([
    [1, 2],
    [3, 4]
])

x.reshape(-1)
```

原来：

```text
shape = (2, 2)
size = 4
```

`reshape(-1)` 表示：

```text
变成一维
↓
这一维长度自动计算
↓
长度 = 4
```

得到：

```text
[1 2 3 4]
```

常见实现：

```python
x.reshape(-1)

x.flatten()

x.ravel()
```

神经网络中通常需要保留 batch：

```text
(32, 64, 7, 7)

↓

(32, 3136)
```

典型写法：

```python
x = x.reshape(x.shape[0], -1)
```

其中：

```text
x.shape[0]
→ 保留第 0 维
→ 通常是 batch size

-1
→ 自动合并其余维度
```

这是一个非常典型的：

> **用 reshape 实现 flatten 的写法。**

# 12. Transpose：转置

二维数组中：

```python
x.T
```

可以理解成：

> 行和列互换

例如：

```text
(2, 3)
↓
(3, 2)
```

一维数组：

```text
shape = (3,)
```

只有 `axis 0`，因此：

```python
x.T
```

前后不变。

## 高维数组中的 transpose

对于三维或更高维数组：

> **transpose 更准确的含义不是简单的“行列互换”，而是重新排列 axes（轴）的顺序。**

例如：

```text
x.shape = (2, 3, 4)
```

```python
x.T
```

把 axes：

```text
0, 1, 2
↓
2, 1, 0
```

所以：

```text
(2, 3, 4)
↓
(4, 3, 2)
```

而：

```python
x.transpose(1, 0, 2)
```

表示新的 axis 顺序是：

```text
原 axis 1
原 axis 0
原 axis 2
```

所以：

```text
(2, 3, 4)
↓
(3, 2, 4)
```

因此：

```text
.T
→ 固定将 axes 倒序

transpose(...)
→ 可以自行指定 axes 顺序
```

图像中常见：

```text
(H, W, C)
↓
(C, H, W)
```

可以：

```python
x = x.transpose(2, 0, 1)
```

# 13. Reshape、Flatten、Transpose 的区别

```text
reshape
→ 重新组织 shape
→ 元素总数不变

flatten
→ 合并多个维度
→ 可以通过 reshape / flatten() / ravel() 实现

transpose
→ 不合并维度
→ 重新排列 axes 的顺序
```

NumPy 很重要的一点，就是可以直接针对整个 ndarray 声明：

```text
我要哪些元素
我要如何筛选
我要如何重排 axis
我要如何改变 shape
```

而不用自己手写大量 Python 循环逐个搬动数据。
