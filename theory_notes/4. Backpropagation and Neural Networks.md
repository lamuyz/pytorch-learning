
# CS231n Lecture 4：Backpropagation and Neural Networks

## 1. 从 Linear Classifier 到 Neural Network

Linear Classifier 的基本形式：

$$
z = Wx + b
$$

如果连续堆叠多个 Linear layer，但中间没有非线性：

$$
z^{(1)} = W_1x + b_1
$$

$$
z^{(2)} = W_2z^{(1)} + b_2
$$

把第一层代入第二层：

$$
z^{(2)}
= W_2(W_1x+b_1)+b_2
$$

展开：

$$
z^{(2)}
= W_2W_1x + W_2b_1 + b_2
$$

重新定义：

$$
W' = W_2W_1
$$

$$
b' = W_2b_1+b_2
$$

于是：

$$
z^{(2)} = W'x+b'
$$

因此：

> 多个 Linear layer 直接堆叠，本质上仍然可以合并成一个线性变换。

为了让网络具有更强的表达能力，需要在 Linear layer 之间加入 **Activation Function（激活函数）**：

$$
z^{(1)} = W_1x+b_1
$$

$$
a^{(1)} = f(z^{(1)})
$$

$$
z^{(2)} = W_2a^{(1)}+b_2
$$

---

## 2. MLP：Multi-Layer Perceptron（多层感知机）

最基本的 MLP：

```text
input x
↓
Linear
↓
z¹
↓
Activation
↓
a¹
↓
Linear
↓
logits
```

数学形式：

$$
z^{(1)} = W_1x+b_1
$$

$$
a^{(1)} = f(z^{(1)})
$$

$$
z^{(2)} = W_2a^{(1)}+b_2
$$

如果第二层是最终分类输出层：

$$
z^{(2)} = \text{logits}
$$

PyTorch：

```python
z1 = self.fc1(x)
a1 = F.relu(z1)
logits = self.fc2(a1)
```

MLP 是多层神经网络的一种，主要由 **fully connected layers（全连接层）** 组成。

## 3. Hidden Layer 和 Neuron

### Hidden Layer（隐藏层）

位于 input 和最终 output layer 之间的层。

例如：

```python
self.fc1 = nn.Linear(4, 5)
self.fc2 = nn.Linear(5, 3)
```

结构：

```text
4 input features
↓
5-neuron hidden layer
↓
3-neuron output layer
↓
3 logits
```

其中：

- `fc1`：hidden layer
- `fc2`：output layer

### Neuron（神经元）

一个 neuron 是一层中的一个输出计算单元。

对于一个 fully connected neuron：

$$
z = w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

一个 neuron：

- 接收当前层全部 input features
- 每个 input feature 对应一个 weight
- 有一个自己的 bias
- 最终产生一个 $z$

因此：

> 一个 neuron 不是一个 weight，而是拥有一组 weights 和一个 bias。

如果有 4 个 input features：

```text
1 neuron
=
4 weights + 1 bias
```

## 4. Weight Matrix 和 Neuron 的关系

假设输入有 3 个 features：

$$
x=
\begin{bmatrix}
x_1\\
x_2\\
x_3
\end{bmatrix}
$$

当前层有 2 个 neurons，那么：

$$
W=
\begin{bmatrix}
w_{11} & w_{12} & w_{13}\\
w_{21} & w_{22} & w_{23}
\end{bmatrix}
$$

其中：

- 第一行：neuron 1 的完整 weight vector
- 第二行：neuron 2 的完整 weight vector

所以：

> Weight matrix 的行数 = neuron 数  
> Weight matrix 的列数 = input feature 数

对于：

```python
nn.Linear(in_features, out_features)
```

有：

$$
\text{shape}(W)
=
(\text{out\_features},\ \text{in\_features})
$$

也就是：

$$
\text{shape}(W)
=
(\text{neuron 数},\ \text{input feature 数})
$$

例如：

```python
nn.Linear(5, 4)
```

表示：

```text
5 input features
↓
4 neurons
↓
4 outputs
```

因此：

$$
\text{shape}(W)=(4,5)
$$

---

## 5. Weight 的意义

某个 weight 表示：

> 某个 input feature 对某个 neuron 输出的影响程度和方向。

例如：

$$
z=w_1x_1+w_2x_2+b
$$

其中：

- $w_1$：$x_1$ 对当前 neuron 的影响
- $w_2$：$x_2$ 对当前 neuron 的影响

一般来说：

- weight 为正：feature 增大时倾向于让 neuron 输出增大
- weight 为负：feature 增大时倾向于让 neuron 输出减小
- 绝对值越大：影响通常越强
- 接近 0：影响较弱

不同 neuron 拥有不同 weights，因此：

> 每个 neuron 学习一种不同的 feature combination（特征组合）。

---

## 6. Input、Feature、Neuron 和 Output 的关系

对于：

```python
nn.Linear(4, 5)
```

可以理解为：

```text
4 input features
↓
5 neurons
↓
5 outputs
```

每一个 neuron 输出一个值，因此：

$$
\text{neuron 数}
=
\text{这一层 output 数}
$$

而这一层的 outputs 又会成为下一层的 input features。

因此：

$$
\text{前一层 neuron 数}
=
\text{前一层 output 数}
=
\text{下一层 input feature 数}
$$

例如：

```python
self.fc1 = nn.Linear(4, 5)
self.fc2 = nn.Linear(5, 3)
```

执行流：

```text
4 input features
↓
5 neurons
↓
5 outputs
↓
成为下一层 5 个 input features
↓
3 neurons
↓
3 logits
```

## 7. Tensor Shape 和 Weight Shape

这是两个不同概念。

### Data Tensor Shape

对于二维 batch：

$$
\text{shape}(x)
=
(\text{batch size},\ \text{features})
$$

例如：

$$
\text{shape}(x)=(32,10)
$$

表示：

- 32 个 samples
- 每个 sample 有 10 个 features

经过：

```python
nn.Linear(10, 8)
```

得到：

$$
(32,10)\rightarrow(32,8)
$$

### Weight Matrix Shape

对于：

```python
nn.Linear(10, 8)
```

有：

$$
\text{shape}(W)=(8,10)
$$

表示：

- 8 个 neurons
- 每个 neuron 有 10 个 weights

注意：

> batch size 不决定 neuron 数，也不会出现在 weight matrix 的 shape 中。

---

## 8. Activation 和 Activation Function

### Activation Function（激活函数）

激活函数作用在 $z$ 上：

$$
a=f(z)
$$

### Activation（激活值）

activation 指激活函数处理之后得到的值。

因此：

- $z$：activation function 之前的值
- $a$：activation function 之后的值

---

## 9. ReLU

**ReLU = Rectified Linear Unit（修正线性单元）**

$$
\operatorname{ReLU}(z)=\max(0,z)
$$

即：

$$
\operatorname{ReLU}(z)=
\begin{cases}
0, & z\le 0\\
z, & z>0
\end{cases}
$$

ReLU 的主要作用：

> 给神经网络加入 nonlinearity（非线性）。

如果没有 activation function，多层 Linear 最终仍然可以化简为一个 Linear。

---

## 10. ReLU 不改变 Tensor Shape

ReLU 是 **element-wise operation（逐元素操作）**。

例如：

$$
z=
\begin{bmatrix}
-2 & 3\\
4 & -1
\end{bmatrix}
$$

经过 ReLU：

$$
a=
\begin{bmatrix}
0 & 3\\
4 & 0
\end{bmatrix}
$$

它只改变元素值，不增加或删除元素，所以 tensor shape 不变。

例如：

$$
(32,5)\rightarrow(32,5)
$$

## 11. Sigmoid、Softmax 和 Logits

### Sigmoid

$$
\sigma(z)
=
\frac{1}{1+e^{-z}}
$$

Sigmoid 会把值映射到 $(0,1)$。

常见于 binary classification（二分类）：

```text
logit
↓
Sigmoid
↓
probability
```

### Softmax

Softmax 常用于 multi-class classification（多分类）：

```text
多个 logits
↓
Softmax
↓
probability distribution
```

在 PyTorch 中：

```python
nn.CrossEntropyLoss()
```

通常直接接收 raw logits，不需要提前手动 Softmax。

## 12. Neural Network Architecture

例如：

```python
self.fc1 = nn.Linear(4, 5)
self.fc2 = nn.Linear(5, 6)
self.fc3 = nn.Linear(6, 3)
```

执行流：

```text
4 features
↓
5-neuron hidden layer
↓
5 activations
↓
6-neuron hidden layer
↓
6 activations
↓
3-neuron output layer
↓
3 logits
```

### Width（宽度）

一层有多少个 neurons。

### Depth（深度）

网络有多少层。

简单理解：

- neuron 数更多 → layer 更宽
- layer 数更多 → network 更深

---

## 13. Output Layer 和 Logits

对于三分类任务：

```python
nn.Linear(..., 3)
```

output layer 有 3 个 neurons。

原因：

```text
3 classes
↓
output layer 设计成 3 neurons
↓
每个 neuron 输出 1 个值
↓
3 logits
```

分类网络的 output layer 通常不接 ReLU。

因为 logits 可以是任意实数，包括负数。

如果加 ReLU，会把负 logits 截成 0，从而丢失原本的 score 信息。

## 14. Forward Pass（前向传播）

两层 MLP：

$$
z^{(1)}=W_1x+b_1
$$

$$
a^{(1)}
=
\operatorname{ReLU}(z^{(1)})
$$

$$
z^{(2)}
=
W_2a^{(1)}+b_2
$$

如果第二层是输出层：

$$
z^{(2)}
=
\text{logits}
$$

然后：

$$
L
=
\operatorname{CrossEntropy}(\text{logits},y)
$$

完整执行流：

```text
input x
↓
Linear
↓
z¹
↓
ReLU
↓
a¹
↓
Linear
↓
logits
↓
Cross-Entropy Loss
↓
loss
```

## 15. Neural Network Backpropagation

Backpropagation（反向传播）的目标，是计算各个 model parameters 对应的 gradients，例如：

$$
\frac{\partial L}{\partial W_1},
\qquad
\frac{\partial L}{\partial b_1},
\qquad
\frac{\partial L}{\partial W_2},
\qquad
\frac{\partial L}{\partial b_2}
$$

Backpropagation 本质仍然是：

> 沿 computation graph 反向使用 Chain Rule（链式法则）。

---

## 16. Weight Gradient

对于一个 neuron：

$$
z=w_1a_1+w_2a_2+b
$$

先看局部导数：

$$
\frac{\partial z}{\partial w_1}
=
a_1
$$

然后使用 Chain Rule：

$$
\frac{\partial L}{\partial w_1}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial w_1}
$$

所以：

$$
\boxed{
\frac{\partial L}{\partial w_1}
=
\frac{\partial L}{\partial z}a_1
}
$$

因此：

> 求 weight gradient 时，需要乘这个 weight 前面对应的 input / activation。

注意：

$$
\frac{\partial z}{\partial w_1}=a_1
$$

但：

$$
\frac{\partial L}{\partial w_1}\neq a_1
$$

因为还要乘上游 gradient：

$$
\frac{\partial L}{\partial z}
$$

---

## 17. Activation Gradient

仍然考虑：

$$
z=w_1a_1+w_2a_2+b
$$

局部导数：

$$
\frac{\partial z}{\partial a_1}
=
w_1
$$

因此：

$$
\frac{\partial L}{\partial a_1}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial a_1}
$$

得到：

$$
\boxed{
\frac{\partial L}{\partial a_1}
=
\frac{\partial L}{\partial z}w_1
}
$$

因此可以记：

```text
求 weight gradient
→ 乘对应 activation

求 activation gradient
→ 乘对应 weight
```

这个关系来自 forward 中的：

$$
w_1a_1
$$

对 $w_1$ 求导留下 $a_1$；

对 $a_1$ 求导留下 $w_1$。

---

## 18. 多条路径的 Gradient Contribution

如果同一个变量通过多条路径影响 loss：

> 每条路径分别使用 Chain Rule 计算 gradient contribution，然后相加。

例如 $a_1$ 同时影响 $z_1$ 和 $z_2$：

$$
\frac{\partial L}{\partial a_1}
=
\frac{\partial L}{\partial z_1}
\frac{\partial z_1}{\partial a_1}
+
\frac{\partial L}{\partial z_2}
\frac{\partial z_2}{\partial a_1}
$$

这和 Lecture 3 的 computation graph 规则一致：

> 同一个变量通过多条路径影响 loss 时，各条路径的 gradient contribution 要相加。

---

## 19. ReLU Backward

如果：

$$
a=\operatorname{ReLU}(z)
$$

那么：

$$
\operatorname{ReLU}'(z)
=
\begin{cases}
0, & z<0\\
1, & z>0
\end{cases}
$$

所以：

$$
\frac{\partial L}{\partial z}
=
\frac{\partial L}{\partial a}
\frac{\partial a}{\partial z}
$$

因此：

```text
z > 0
→ gradient 原样通过

z < 0
→ gradient 变成 0
```

注意：

> gradient 变成 0 的直接原因，不是因为 $a=0$，而是因为 ReLU 在该区域的局部导数为 0。

---

## 20. ReLU 对 Weight Gradient 的影响

如果某个 hidden neuron：

$$
z<0
$$

那么 backward 时：

$$
\frac{\partial L}{\partial z}=0
$$

而这个 neuron 前面的某个 weight：

$$
\frac{\partial L}{\partial w_i}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial w_i}
$$

对于：

$$
z=w_ix_i+\cdots
$$

有：

$$
\frac{\partial z}{\partial w_i}
=
x_i
$$

所以：

$$
\frac{\partial L}{\partial w_i}
=
\frac{\partial L}{\partial z}x_i
$$

当：

$$
\frac{\partial L}{\partial z}=0
$$

就有：

$$
\frac{\partial L}{\partial w_i}=0
$$

因此：

> 对当前 sample 来说，这个 neuron 前面的 weights 不会得到来自该 sample 的更新信号。

---

## 21. Bias Gradient

对于：

$$
z=\cdots+b
$$

局部导数：

$$
\frac{\partial z}{\partial b}=1
$$

因此：

$$
\frac{\partial L}{\partial b}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial b}
$$

所以：

$$
\boxed{
\frac{\partial L}{\partial b}
=
\frac{\partial L}{\partial z}
}
$$

bias gradient 直接继承上游 gradient。

---

## 22. 两层 MLP 的完整 Backward Flow

Forward：

```text
x
↓
z¹ = W₁x + b₁
↓
a¹ = ReLU(z¹)
↓
z² = W₂a¹ + b₂
↓
logits
↓
loss
```

Backward：

```text
loss
↓
∂L/∂z²
↓
计算 ∂L/∂W₂、∂L/∂b₂
同时得到 ∂L/∂a¹
↓
穿过 ReLU
↓
得到 ∂L/∂z¹
↓
计算 ∂L/∂W₁、∂L/∂b₁
```

---

## 23. Gradient Shape

参数和它对应的 gradient 必须具有相同 shape。

例如：

$$
\operatorname{shape}(W_1)=(3,2)
$$

那么：

$$
\operatorname{shape}
\left(
\frac{\partial L}{\partial W_1}
\right)
=
(3,2)
$$

因为 $W_1$ 中每一个 weight，都必须有一个一一对应的 gradient。

例如：

$$
W=
\begin{bmatrix}
w_{11} & w_{12}\\
w_{21} & w_{22}
\end{bmatrix}
$$

对应：

$$
\frac{\partial L}{\partial W}
=
\begin{bmatrix}
\frac{\partial L}{\partial w_{11}}
&
\frac{\partial L}{\partial w_{12}}
\\
\frac{\partial L}{\partial w_{21}}
&
\frac{\partial L}{\partial w_{22}}
\end{bmatrix}
$$

## 24. PyTorch 中的 Backpropagation

Forward：

```python
logits = model(x)
loss = criterion(logits, y)
```

然后：

```python
loss.backward()
```

负责：

> 从 loss 出发，沿 computation graph 反向使用 Chain Rule，计算各参数的 gradients。

例如：

```python
model.fc1.weight.grad
model.fc1.bias.grad
model.fc2.weight.grad
model.fc2.bias.grad
```

分别对应：

$$
\frac{\partial L}{\partial W_1},
\qquad
\frac{\partial L}{\partial b_1},
\qquad
\frac{\partial L}{\partial W_2},
\qquad
\frac{\partial L}{\partial b_2}
$$

---

## 25. `loss.backward()` 和 `optimizer.step()`

### `loss.backward()`

负责计算 gradients：

```text
loss
↓
backpropagation
↓
parameter.grad
```

### `optimizer.step()`

负责根据 gradient 和 learning rate 更新 parameters。

以 SGD 为例：

$$
W
\leftarrow
W-\eta\frac{\partial L}{\partial W}
$$

因此：

```text
loss.backward()
= 计算 gradients

optimizer.step()
= 使用 gradients 更新 parameters
```

注意：

> “反向”的是 gradient computation，而不是 parameter update。

## 26. Lecture 4 核心执行流

Forward：

```text
input features
↓
Linear
z = Wx + b
↓
Activation
a = f(z)
↓
下一层
↓
最终 logits
↓
loss
```

Backward：

```text
loss
↓
Chain Rule
↓
output layer gradients
↓
activation gradients
↓
穿过 activation function
↓
前一层 gradients
↓
直到所有 parameters 的 gradients 都被计算出来
```

PyTorch 中：

```python
loss.backward()
```

完成 gradient computation。

```python
optimizer.step()
```

完成 parameter update。

## 27. 最核心的关系

对于：

```python
nn.Linear(in_features, out_features)
```

有：

$$
\text{out\_features}
=
\text{neuron 数}
=
\text{这一层 output 数}
$$

Weight matrix：

$$
\operatorname{shape}(W)
=
(\text{out\_features},\ \text{in\_features})
$$

也就是：

$$
\operatorname{shape}(W)
=
(\text{neuron 数},\ \text{input feature 数})
$$

Data tensor：

$$
\operatorname{shape}(x)
=
(\text{batch size},\ \text{当前 feature/output 数})
$$

层与层之间：

$$
\text{前一层 output 数}
=
\text{下一层 input feature 数}
$$

Forward：

$$
z=Wx+b
$$

$$
a=f(z)
$$

Backprop：

$$
\frac{\partial L}{\partial w}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial w}
$$

如果：

$$
z=wa+\cdots
$$

那么：

$$
\frac{\partial z}{\partial w}=a
$$

所以：

$$
\frac{\partial L}{\partial w}
=
\frac{\partial L}{\partial z}a
$$

同时：

$$
\frac{\partial z}{\partial a}=w
$$

所以：

$$
\frac{\partial L}{\partial a}
=
\frac{\partial L}{\partial z}w
$$

最后：

> 同一个变量通过多条路径影响 loss 时，各条路径的 gradient contributions 要相加。
