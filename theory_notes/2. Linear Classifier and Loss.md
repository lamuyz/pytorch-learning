# CS231n Lecture 2：Linear Classifier and Loss

## 1. Data-driven Approach 与 K-Nearest Neighbor

**Data-driven Approach：数据驱动方法**

图像分类不再依赖人工编写大量判断规则，而是：

```text
training data
↓
learning algorithm
↓
classifier
```

---

### K-Nearest Neighbor

**K-Nearest Neighbor，KNN：K 近邻算法**

预测新样本时：

```text
test image
↓
寻找最相似的 K 个 training samples
↓
根据邻居类别投票
↓
prediction
```

---

### L1 Distance

**L1 Distance：L1 距离**

又称：

**Manhattan Distance：曼哈顿距离**

公式：

d(I1,I2)=∑p∣I1p−I2p∣d(I_1,I_2)=\sum_p |I_1^p-I_2^p|

其中：

```text
p
```

表示 pixel / position（像素位置）索引。

KNN 的主要问题：

```text
training 很快
prediction 很慢
```

而且：

```text
pixel similarity
≠
semantic similarity
```

因此不适合作为复杂视觉任务的主要方法。

# 2. Linear Classifier

**Linear Classifier：线性分类器**

核心公式：

scores=Wx+bscores=Wx+b

其中：

```text
x = input features

W = weight matrix

b = bias

scores = 各类别分数
```

---

## x

如果 CIFAR-10 图片：

```text
32 × 32 × 3
```

Flatten 后：

```text
3072
```

因此：

```text
x = [x1, x2, ..., x3072]
```

`x` 是一个包含 3072 个输入值的 vector，而不是数字 3072。

---

## W

每个类别都有自己的一组 weights。

例如：

```text
w_cat
w_dog
w_frog
```

把这些 weight vectors 组合起来：

```text
W
```

就是整个 weight matrix。

如果：

```text
10 classes
3072 input features
```

则：

```text
W.shape = [10, 3072]
```

每个类别的 score 本质上是：

scorec=wc⋅x+bcscore_c=w_c\cdot x+b_c

也就是：

```text
每个 input feature
×
对应 weight
↓
全部相加
↓
+bias
↓
class score
```

---

## Bias

**Bias：偏置**

`b` 和 `W` 一样，也是模型需要学习的 parameter。

可以理解成：

> 不依赖输入 x 的基础偏移量。

与：

y=kx+by=kx+b

中的 `b` 含义类似。

---

## PyTorch 对应

```python
nn.Linear(3072, 10)
```

内部主要包含：

```text
weight.shape = [10, 3072]
bias.shape   = [10]
```

执行：

```python
scores = layer(x)
```

本质就是：

scores=Wx+bscores=Wx+b

# 3. Linear Classifier 的三种理解方式

## Algebraic Viewpoint

**Algebraic Viewpoint：代数视角**

```text
x
↓
matrix multiplication
↓
Wx+b
↓
scores
```

---

## Visual Viewpoint

**Visual Viewpoint：视觉视角**

每个类别对应一个：

**Class Template：类别模板**

例如：

```text
w_cat
```

可以粗略理解成 Linear Classifier 学到的：

> 什么样的输入 pattern 更支持 cat。

如果输入来自一张 flatten 后的图片，可以把 `w_cat` reshape 回原图大小进行可视化。

这个 reshape 只是为了人类观察，不是模型 forward 必须执行的步骤。

---

## Geometric Viewpoint

**Geometric Viewpoint：几何视角**

如果输入只有两个 feature：

```text
x = [x1, x2]
```

每个样本可以看作二维空间中的一个点。

Linear Classifier 用：

```text
line
```

分隔不同类别。

如果是三维：

```text
plane
```

如果是高维：

**Hyperplane：超平面**

因此 Linear Classifier 可以理解为：

```text
feature space
↓
linear decision boundary
↓
different classes
```

# 4. Softmax 与 Cross-Entropy Loss

Linear Classifier 首先输出：

```text
scores / logits
```

例如：

```text
[2, 1, 0]
```

这些数字还不是 probability。

---

## Softmax

**Softmax Function：Softmax 函数**

又称：

**归一化指数函数**

作用：

```text
scores
↓
probability distribution
```

公式：

pi=esi∑jesjp_i= \frac{e^{s_i}} {\sum_j e^{s_j}}

例如：

```text
scores = [2, 1, 0]
```

Softmax 后约为：

```text
[0.665, 0.245, 0.090]
```

满足：

```text
每个 probability ≥ 0

所有 probabilities 总和 = 1
```

---

## Cross-Entropy Loss

**Cross-Entropy Loss：交叉熵损失**

对于正确类别：

L=−log⁡(pcorrect)L=-\log(p_{correct})

其中：

```text
p_correct
```

是模型分给 ground truth 类别的 probability。

因此：

```text
正确类别 probability 越高
↓
loss 越小

正确类别 probability 越低
↓
loss 越大
```

---

## PyTorch 对应

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, labels)
```

通常不需要提前手动：

```python
softmax(logits)
```

`CrossEntropyLoss` 可以直接接收 logits。

执行流：

```text
logits
↓
Softmax / Cross-Entropy 相关计算
↓
loss
```

---

# 5. Batch Loss 与训练目标

真实训练通常一次处理一个 batch。

假设：

```text
batch_size = N
```

每个 sample 都会产生自己的 loss：

```text
L1
L2
L3
...
LN
```

然后通常取平均：

L=1N∑i=1NLiL=\frac{1}{N}\sum_{i=1}^N L_i

得到：

```text
batch loss
```

PyTorch 中：

```python
loss = criterion(logits, labels)
```

默认通常就是返回整个 batch 的平均 loss。
